## Verify your download

Download the PDF from the official link above and the `.sha256` file from this repository. Calculate the PDF's SHA-256 checksum locally.

### macOS

Run this command in the folder containing the downloaded PDF:

```sh
shasum -a 256 Approved-Then-Changed-v1.0.0.pdf
```

### Linux

```sh
sha256sum Approved-Then-Changed-v1.0.0.pdf
```

### Windows PowerShell

```powershell
Get-FileHash -Algorithm SHA256 .\Approved-Then-Changed-v1.0.0.pdf
```

Compare the resulting hash with the value below. All 64 characters must match; uppercase and lowercase hexadecimal letters are equivalent.

```text
d903d798aa7193406b5e9b4127df1b6322c59055c2e4cf1072c0e6a3168b6b7e
```

A match confirms that the files are byte-for-byte identical. A mismatch means the files differ; it does not, by itself, establish malicious alteration. Download the official edition again and verify that you are comparing the same version.

## Version policy

Each revised PDF receives a distinct version and checksum. Earlier version records are retained so readers can verify previous editions. Do not use this checksum to verify a different edition or a PDF that has been re-exported or otherwise modified.
